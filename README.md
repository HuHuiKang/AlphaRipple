# AlphaRipple

基于大语言模型与图神经网络的 A 股产业链传导分析系统。

> 项目处于早期开发阶段，以下内容为设计目标与规划。

## 项目简介

量化投资的前沿方向之一，是对非结构化另类数据进行全自动提取与语义量化。AlphaRipple 关注其中的产业链传导问题：

上游原材料价格波动时，影响会沿供应链逐级传到下游企业。这种传导关系分散在招股书、研报、公告等大量文本里，很难靠人工整理。本项目尝试用大语言模型（LLM）自动从这些文本中抽取产业链关系，构建 A 股动态产业链图谱，再用图神经网络（GNN）推演价格冲击对下游标的利润的边际影响，从而生成领先于市场的 Alpha 信号。

## 核心模块

### 1. 数据采集
- 上市公司招股说明书
- 券商研究报告
- 供应链相关公告
- 专利数据库

### 2. 产业链图谱自动构建
- 用 LLM 解析文本，抽取"供应商—客户""原材料—产品"等关系
- 将抽取结果组织成产业链知识图谱
- 随新公告和新数据持续更新图谱

### 3. 传导推演
- 用 GNN 在图谱上建模冲击的逐级传导
- 当上游原材料价格变动时，估算其对下游数千家细分标的利润的边际影响
- 目标是低延迟推演，能及时响应价格变化

### 4. Alpha 信号生成
- 把推演结果转化为可交易的超前信号
- 对信号进行回测与评估

## 开发路线

- [ ] 数据采集与清洗
- [ ] LLM 关系抽取
- [ ] 产业链图谱构建与存储
- [ ] GNN 传导模型
- [ ] 信号生成与回测
